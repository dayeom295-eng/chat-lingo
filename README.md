# 챗링고 (ChatLingo)

실리태번에서 채팅하며 만난 일본어와 영어를 바로 공부하는 한국인용 언어 학습 확장입니다.

---

## 핵심 기능

- 선택 문장·직접 입력·최근 AI 답변 분석
- 문맥에 맞는 번역, 한글 발음, 문법, 핵심 단어와 예문 제공
- 일본어 한자와 가타카나의 후리가나 표시
- 대사만 가져오기 또는 AI 답변 전체 가져오기
- 분석 단어를 골라 개인 단어장에 저장
- 단어장 내용 수정·정렬·선택 삭제·중복 병합·빈 뜻 자동 채우기·JSON 백업과 복원
- 기기 기본 무료 음성 또는 실리태번 TTS로 재생
- 현재 메인 API 또는 별도의 연결 프로필 선택

---

## 기본 설정

- 자동 문맥 범위: 사용 안 함
- 최대 출력 토큰: 6000
- 최근 AI 답변 가져오기: 대사만(따옴표 안)
- 음성 연결: 기기 기본 음성(무료)

캐릭터와 사용자 이름만 문맥 구분에 사용하며, 프로필 설명·로어북·메모리는 자동으로 가져오지 않습니다. `서사 추가`에 관계나 상황을 직접 적으면 분석에 함께 반영됩니다.

---

## 설치

이 폴더를 `chatlingo`라는 이름으로 아래 위치 중 하나에 넣고 실리태번을 새로고침합니다.

- 개인 설치: `SillyTavern/data/default-user/extensions/chatlingo`
- 개발 설치: `SillyTavern/public/scripts/extensions/third-party/chatlingo`

---

## 알아둘 점

- AI 분석 비용과 정확도는 연결한 API와 모델에 따라 달라집니다.
- 기기 기본 음성의 종류와 품질은 운영체제와 브라우저에 따라 다릅니다.
- 단어장은 실리태번의 확장 설정에 저장되므로 기기 이동 전 JSON 백업을 권장합니다.
- 단어 개수와 백업 파일 크기에 별도 상한은 없지만, 아주 큰 단어장은 기기 성능과 저장공간에 따라 느려질 수 있습니다.
